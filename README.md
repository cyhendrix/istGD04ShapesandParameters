# Lesson 04: Shapes and Parameters

IST Unit 03 practice lab for Fitzgerald High School College and Career Academy.

## Activities
- Identify: six clear vocabulary matches.
- Build: four target drawings; drag numbers into x, y, width, and height slots. Click-to-place and dropdown controls are also available.
- Apply: four predictions about size, position, and background.
- Debug: three corrections for swapped dimensions, background order, and position.

17 scored items, converted to a percentage. Each complete Build drawing earns one point. A perfect first check completes each activity; otherwise students have one additional check. Answer feedback appears only after checking. Questions, answer options, and number banks are shuffled per attempt. Progress is saved in the browser. Reset requires confirmed final-grade submission and never removes recorded grades.

## Deployment
Enable GitHub Pages from main, root folder. The student information page appears first.

Grade submission remains disabled until the shared Game Design Grade Submission Apps Script is updated with grade-submission.gs and deployed as a new version. This script supports Lessons 01 through 04. Then enable SUBMISSION_READY in index.html and test the submission and reset workflow before adding the lab to the hub.
